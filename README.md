# Voter Street 🗳️

A 3D Neighbourhood Arcade Game built with Three.js exploring South African community dynamics, canvassing, and dialogue.

## Features
- **3D Interactive Neighbourhood**: Explore neighbourhood streets with custom buildings, roads, and Table Mountain backdrop.
- **Community Characters & Dialogue**: Engage with local residents, canvassers, taxi guards, vendors, and community members.
- **Political Party Context**: Integrated party logos, stances, and community dialogue mechanics.
- **Atmospheric Audio**: Dynamic background music and sound effects.

## Getting Started

### Prerequisites
- Node.js (v16 or newer recommended)

### Installation & Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Voomay/game.git
   cd game
   ```

2. Start the local server:
   ```bash
   npm start
   ```

3. Open in your browser:
   [http://localhost:3000](http://localhost:3000)

## Tech Stack
- **Three.js** - 3D Graphics & Canvas rendering
- **HTML5 / CSS3 / Vanilla JavaScript**
- **Node.js HTTP Server**
