# Campaign Trail Assets Directory

This directory contains the structure for custom artwork, sprite sheets, and audio files.
When you add your own PNG files and audio assets here, configure their paths in `src/config/assets.ts`.

## Structure:
- `backgrounds/`: `sky/`, `clouds/`, `houses/`
- `roads/`: `clean/`, `damaged/`
- `players/`: `da/`, `anc/`, `pa/` (character sprite sheets / idle / run / jump / hit frames)
- `residents/`: `idle/`, `happy/`, `doubtful/`, `frustrated/`
- `obstacles/`: `potholes/`, `rubbish/`, `pipes/`, `streetlights/`
- `ui/`: `buttons/`, `icons/`, `dialogue/`
- `audio/`: `music/`, `effects/`
